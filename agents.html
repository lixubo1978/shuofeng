代理商资金信息
用于代理商正式下单。创建成功后由充值和订单系统维护。
押金在创建代理商时初始化，不计入销售账户余额，也不参与订单扣款。
账户余额和押金使用同一币种。
开户资金合计 = 初始账户余额 + 押金，仅用于显示。
销售账户余额： 创建后不能在代理商资料中人工修改。 后续只能通过正式充值增加，或由代理商正式订单自动扣减。
代理商押金： 与销售账户余额独立。 正常经营期间不参与订单消费； 代理商设为无效时，剩余账户余额与押金一起进入退款责任。
创建成功后，系统会同时建立 Authentication 登录账号、 profiles 的 agent 身份和 agents 代理商资料。 代理商从 page11.html 登录。
